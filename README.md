# Консольный банкомат на Java

Мой первый проект на Java. Написал консольный банкомат, чтобы на практике разобраться, как работает объектно-ориентированное программирование (ООП), логика объектов и базовые проверки в коде.

## Как устроена программа (Структура классов)
Код разделен на 4 отдельных файла:
*   `User` — хранит данные пользователя (имя и пин-код).
*   `Account` — отвечает за кошелек, баланс и операции с деньгами.
*   `ATM` — управляет консольным меню, считывает ввод с клавиатуры через `Scanner` и проверяет пароли.
*   `Main` — точка запуска, где захардкожены тестовые данные (пользователь Иван и его стартовый баланс).

## Что умеет приложение
*   **Вход по логину и паролю**: пускает к меню только в том случае, если введенное имя и пин-код совпали с данными владельца счета.
*   **Пополнение и снятие**: баланс реально обновляется в памяти при каждой операции.
*   **Защита баланса**: банкомат не даст уйти в минус — перед снятием код проверяет, хватает ли денег на счету.
*   **Безопасность данных**: все переменные скрыты внутри классов и меняются только через специальные методы, а не напрямую.

## Как запустить у себя
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/kerrraa/ATM-console.git
   ```
2. Откройте проект в IntelliJ IDEA.
3. Запустите файл `Main.java` и следуйте подсказкам в консоли.
